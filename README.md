# Movie Data Analysis

A beginner-friendly data science project analyzing the TMDB 5000 Movie Dataset from Kaggle.

## 📊 What I Analyzed
- Top movie genres
- Revenue trends over time (1960–2020)

## 🛠️ Tools Used
- Python
- Pandas
- Matplotlib & Seaborn
- Google Colab
- Kaggle API

## 📂 Files
- `movie_analysis.ipynb` – Jupyter Notebook with full analysis

## 📌 My Findings
- The most popular movie genre: Drama  
- Movie revenue increased significantly during the 2010s.  
- I learned how to download data from Kaggle, clean JSON-formatted data, and create visualizations.
